# 03. Admission ledger

Status: draft for review, 2026-11-01. Every candidate considered for v8 gets one row and one decision: v7's components, the projects the owner named, new tools found in research, and ideas from the omission scout. Evidence tiers E1 to E5 are defined in [09-evaluation-plan.md](09-evaluation-plan.md); sources and dates are in [14-sources.md](14-sources.md). Once the registry exists, the registry entry is the source of truth and this page is generated from it (ADR-0004).

## Decision rules

| Decision | Meaning | Default in setup |
| --- | --- | --- |
| Adopt | Evidence from a comparable setting (E1, or E2 plus a passing maintainer bench), mature enough to depend on, cost justified against the simpler alternative. | On |
| Trial, on | A Trial that meets all four conditions: first-party plugin or owned text (machine tools it needs are pinned and send nothing anywhere); no egress and nothing in the request path; reversible by the engine; scheduled in the v8.0 maintainer bench. The first bench result moves it to Adopt or to Trial, off. | On, labeled "Trial" in the plan |
| Trial, off | Plausible mechanism and a kill test that can fail. | Shown, unchecked |
| Assess | Worth watching; setup does not offer it. | Not offered |
| Hold | A clear reason to wait and a named trigger. | Not offered |
| Reject | Fails a hard constraint or has negative evidence; a reversal trigger is named where one exists. | Never offered |

**Engine features.** Some rows are features of the engine or the repository itself: a `verify` check, a bench method, an accounting rule, a writing standard checked in CI. They install nothing into the user's configuration, have no registry entry and aren't offered in setup, so the evidence tiers don't gate them; the requirements in [04-requirements.md](04-requirements.md) and the decision records in [12-decision-records.md](12-decision-records.md) do. They are marked "Adopt (engine)" or "Trial (engine)", and a Trial (engine) row still has a kill test that can remove it.

Columns below compress the full ledger format: "What it does" and "Mechanism" are in the Candidate cell, maturity is in the Evidence cell.

**v7 users:** v8's evidence rule is stricter than v7's "Use". Ponytail and the working rules move from Use to Trial. Nothing already installed is removed without a consented plan row ([11-migration-and-roadmap.md](11-migration-and-roadmap.md)).
